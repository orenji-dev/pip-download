## 它教你的几条铁律

这些不是随口编的，是写死在软件里的判断逻辑：

### 铁律一：别说客服话

```
她说「今天好忙」
❌ 「辛苦了，早点休息」   ← 这是客服，不是撩
❌ 「注意身体」          ← 等于没回
```

**她不需要你的关心通知，她需要有人接得住话。**

### 铁律二：别停在原地

```
她说「杭州空气不好」
❌ 「苏州空气应该好很多吧」  ← 你还在聊空气
```

**一句话聊完就该往前走，不是原地打转。**

### 铁律三：别自作多情

```
她问「这个作业怎么做」
❌ 以为她对你有意思
```

软件会提醒你：**换成普通同学她还会这么说吗？会 → 那就是问作业。**

### 铁律四：别跳级

从**破冰 → 好感 → 升温 → 邀约 → 约会**，五个阶段。

**单条线索不许跳级**——亲昵称呼、回复频率、问年龄收入，这些都不够。

## 第一次用（三步）

### 1. 准备一个 AI 的 Key

橙瓣本身不含 AI 模型，需要你自备一个。推荐 **DeepSeek**，便宜，充 10 块钱能用很久：

1. 打开 <https://platform.deepseek.com/>
2. 注册登录
3. 左边「API keys」→「创建 API key」
4. 复制那串 `sk-` 开头的内容

### 2. 填进橙瓣

首次打开会一步一步引导你填，能点「测试连接」当场验证。

### 3. 开始用

1. 打开聊天软件，停在你要回复的那个会话
2. 打开橙瓣标题栏上的**采集开关**
3. 对方发来新消息 → 三条建议出现在橙瓣里
4. 点一条 → 填进输入框 → **你自己按回车**

## 常见问题

**Q：这是不是套路话术软件？**
A：它给的是**针对你们这段对话**的具体回法，不是通用模板。而且软件内置的判断逻辑明确反对套话（「注意身体」「早点休息」这种直接被标成错误示范）。

**Q：识别不准怎么办？**
A：聊天窗口不要缩放或改大小。窗口尺寸变了可能影响识别。

**Q：对方发语音怎么办？**
A：读不到语音内容。**长按那条语音 → 选「转文字」**，转出来的文字它就能读了。

**Q：换电脑要重新买吗？**
A：机器码会变，需要重新获取授权码。联系作者说明情况。

**Q：会被封号吗？**
A：软件只读屏幕，不登录、不改设置、不修改聊天软件。但聊天软件的服务条款通常不允许第三方工具读取屏幕，**使用风险由你自己承担**。

**Q：支持 QQ / 钉钉 / 飞书吗？**
A：当前版本针对桌面聊天窗口设计。其他软件的适配情况见 Release 说明。
