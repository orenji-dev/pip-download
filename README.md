## 它怎么帮你的

### 三条建议，三种性格

同一句话，它给你三条不一样的回法：

```
她说：今天开了六个会 累死了

① 「六个？你是去开会还是去受刑」
② 「那今晚别想了，睡觉」
③ 「你老板是不是以为你是永动机」
```

**挑一条顺眼的，填进去，你自己按回车。**

### 内置恋爱场景的判断逻辑

不是随便说说，里面写死了几条规矩：

| 它不会做的事 | 为什么 |
|---|---|
| 她说「好累」你回「注意身体」 | **这是客服话术，等于没回** |
| 她说「杭州空气不好」你回「苏州应该好很多」 | **还在聊空气，没往前走** |
| 她问「这个作业怎么做」就以为她有意思 | **那是问作业** |

**它内置了一整套「什么时候该进、什么时候别自作多情」的判断**，比你自己瞎猜靠谱。

### 能看懂图片

她发来一张照片，它也能接住——图里是什么、好笑在哪、值不值得问一句。

### 会学你的说话方式

你可以告诉它你平时怎么讲话：字数长短、爱不爱用表情、口头禅是什么。

**给出来的建议会像你说的，不像 AI 说的。**

### 每个聊天分开记

跟不同的人聊，它不会串台。每个聊天单独记上下文。

### 觉得这条不用回？也给选项

有时候它判断「这条可以不回」，但你还是想搭一句——

页面上有个「还是想回一句」的按钮，点了它会给三条**轻量的、随口就能发的**短句。

## 第一次用（三步）

### 1. 准备一个 AI 的 Key

橙瓣本身不含 AI 模型，需要你自备一个。推荐 **DeepSeek**，便宜，充 10 块钱能用很久：

1. 打开 <https://platform.deepseek.com/>
2. 注册登录
3. 左边「API keys」→「创建 API key」
4. 复制那串 `sk-` 开头的内容

### 2. 填进橙瓣

首次打开会一步一步引导你填，还能点「测试连接」当场验证。

### 3. 开始用

1. 打开聊天软件，停在你要回复的那个会话
2. 打开橙瓣标题栏上的**采集开关**
3. 对方发来新消息 → 三条建议出现在橙瓣里
4. 点一条 → 填进输入框 → **你自己按回车**

## 常见问题

**Q：这是不是那种套路话术软件？**
A：不是。它给的是**针对你们这段对话**的具体回法，不是通用模板。而且它内置的判断逻辑明确反对套话（「注意身体」「早点休息」这种直接被标成错误示范）。

**Q：识别不准怎么办？**
A：聊天窗口不要缩放或改大小。窗口尺寸变了可能影响识别。

**Q：对方发语音怎么办？**
A：读不到语音内容。**长按那条语音 → 选「转文字」**，转出来的文字它就能读了。

**Q：换电脑要重新买吗？**
A：机器码会变，需要重新获取授权码。联系作者说明情况。

**Q：会被封号吗？**
A：软件只读屏幕，不登录、不改设置、不修改聊天软件。但聊天软件的服务条款通常不允许第三方工具读取屏幕，**使用风险由你自己承担**。

**Q：支持 QQ / 钉钉 / 飞书吗？**
A：当前版本针对桌面聊天窗口设计。其他软件的适配情况见 Release 说明。
