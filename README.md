## 这是什么

一个坐在你屏幕边上的小助手。

它看着你正在聊天的那个窗口，读出对方说了什么，然后给你**三条**回复建议——每条都标了策略，比如"逗她一下""直接回答""安抚一下"。

你点一条，它填进输入框。**发不发、什么时候发，你自己按回车。**

## 第一次用（三步）

### 1. 准备一个 AI 的 Key

橙瓣本身不含 AI 模型，需要你自备一个。推荐 **DeepSeek**，便宜，充 10 块钱能用很久：

1. 打开 <https://platform.deepseek.com/>
2. 注册登录
3. 左边「API keys」→「创建 API key」
4. 复制那串 `sk-` 开头的内容

### 2. 填进橙瓣

首次打开会一步一步引导你填，还能点「测试连接」当场验证能不能用。

### 3. 开始用

1. 打开聊天软件，停在你要回复的那个会话
2. 打开橙瓣标题栏上的**采集开关**
3. 对方发来新消息 → 三条建议出现在橙瓣里
4. 点一条 → 填进输入框 → **你自己按回车**

## 它能做到什么

| 功能 | 说明 |
|---|---|
| **看懂聊天** | 屏幕上的对话，它都能读 |
| **三条建议** | 不同策略、不同语气，你自己挑 |
| **看懂图片** | 对方发的图，它也能理解 |
| **学你的语气** | 你可以写一段自己平时怎么说话，它照着来 |
| **多会话分开记** | 每个聊天单独记上下文，不会串 |
| **自动切会话** | 别的会话来新消息时自动切过去（默认关闭） |

## 常见问题

**Q：识别不准怎么办？**
A：聊天窗口不要缩放或改大小。窗口尺寸变了可能影响识别准确度。

**Q：对方发语音怎么办？**
A：软件读不到语音内容。**长按那条语音 → 选「转文字」**，转出来的文字它就能读了。

**Q：换电脑要重新买吗？**
A：机器码会变，需要重新获取授权码。联系作者说明情况。

**Q：会被封号吗？**
A：软件只读屏幕，不登录、不改设置、不修改聊天软件。但聊天软件的服务条款通常不允许第三方工具读取屏幕，**使用风险由你自己承担**。详见软件内的《用户协议》。

**Q：支持 QQ / 钉钉 / 飞书吗？**
A：当前版本针对桌面聊天窗口设计。其他软件的适配情况见 Release 说明。

**Q：需要一直开着吗？**
A：只有想用的时候开就行。关掉软件不影响任何东西。
